# Tools page logo assets

These local SVGs identify the tools listed on the Verktøy page. They require no
third-party requests at runtime. Brand names and marks belong to their respective
owners; their presence describes tools used, without implying endorsement.

## Simple Icons

`figma.svg`, `canva.svg`, `googleanalytics.svg`, `googlesearchconsole.svg`,
`wordpress.svg`, `claude.svg`, `openai.svg`, and `obsidian.svg` come from
[Simple Icons 13.21.0](https://github.com/simple-icons/simple-icons/tree/13.21.0/icons),
distributed under CC0-1.0. The complete package license is included in
`SIMPLE-ICONS-LICENSE.md`. Original path data is retained; a single high contrast
fill color was added to each SVG for the dark interface. `openai.svg` identifies
ChatGPT in the visible tool list.

Download pattern:
`https://cdn.jsdelivr.net/npm/simple-icons@13.21.0/icons/<filename>.svg`

## Rank Math

`rankmath.svg` is the unmodified white menu icon from the
[official Rank Math WordPress plugin](https://plugins.svn.wordpress.org/seo-by-rank-math/trunk/assets/admin/img/menu-icon.svg).
The plugin's [readme](https://plugins.svn.wordpress.org/seo-by-rank-math/trunk/readme.txt)
identifies GPL-3.0-or-later. The corresponding license text is included in
`RANK-MATH-LICENSE.txt`.

## Visual Studio Code

`visualstudiocode.svg` is the unmodified stable icon (`vscode.svg`) from the
[official VS Code icon download](https://code.visualstudio.com/assets/branding/visual-studio-code-icons.zip).
The icon is provided under Microsoft's
[VS Code icon and name usage guidelines](https://code.visualstudio.com/brand).

## Typographic treatments

The Adobe Creative Cloud applications use compact HTML text tiles (Ai, Ps, Id,
Ae) with visible application names. These are original typographic treatments,
not downloaded logo artwork. Klang.ai similarly uses a simple HTML wordmark;
it does not claim to reproduce an official logo. All tool names remain readable
without images. Decorative images have empty alt text to avoid repeating those
visible names for screen reader users.
